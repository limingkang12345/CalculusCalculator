# 表达式画布（Expression Canvas）

一个基于 **PySide6 + QWebEngineView + MathJax** 的数学表达式编辑与变形演示项目。

项目把 SymPy 表达式转换为自定义表达式树，按节点层级着色渲染到 HTML 画布上，并支持节点选中、拖拽布局、结构操作、SymPy 变形与撤销/重做。

## 功能特性

- SymPy 表达式 → 自定义表达式树，**保留输入顺序与括号**（`evaluate=False`）。
- 支持微积分与求解结果直接上画布：求导（含高阶、偏导）、积分（不定/定积分、多重积分嵌套）、分段函数、不等式、逻辑连接、有限集，均可逐节点选中与变形。
- 常用方程面板：圆、直线、椭圆、双曲线、抛物线模板；参数可直接填，也可留空保留符号；支持「通过条件创建」——用点、离心率、准线等条件联立反推参数，解出多组就生成多张卡片。
- 节点操作支持换元：输入换元符号与换元式（如 `t` 与 `x+1`），程序由 `t = x+1` 解出 `x = t-1`，把整张卡片的 `x` 全部代换后展开。
- 支持点：输入 `(a, b)` 直接生成点卡片；「添加几何表达式」可算点到直线距离、两直线交点、交点线段中点与三角形面积。
- 卡片可折叠：折叠后仍**排版渲染公式**（单色黑色、字号约 2/3、随滑块缩放），但不带任何交互——不能点节点、没有悬停徽标。
- 变形结果可选 **覆盖原表达式** 或 **保存为副本**（副本是一张新卡片，原卡片不变）。
- 每张卡片可设置标题（双击编辑），选中卡片时卡片带蓝色边缘高光。
- 右侧属性区显示所选卡片的标题、表达式、变量与**取值范围**，宽度可用分隔条拖动调整。
- 多表达式画布：任意添加、自动避让摆放、拖拽移动。
- 表达式按树深度着色：**红 → 绿 → 蓝 → 紫**，超过四层循环。
- 节点级交互：
  - 点击选中、悬停灰底；
  - 加号/减号交换相邻项；
  - 括号展开；
  - 选中节点拖拽为“浮动节点”，松手若与某条表达式重叠则弹出操作对话框；
  - 选中节点化简/变形。
- “变”对话框：SymPy 变形（simplify / expand / factor / …）+ 基于输入表达式的节点操作（替换、追加、追乘、倒数、除以、平方、算术平方根、乘方）。
- 方程支持：输入 `x=y` 生成自定义 `Eq` 节点；选中方程并点击“变”可弹出求解窗口，按变量与求解范围求根，每个根生成一张独立卡片。
- 卡片右下角提供 **复制 / 删除** 按钮；复制自动避让摆放，删除与复制均可撤销/重做。
- 拖拽一张方程卡片与另一张方程卡片重叠时，弹出**联立窗口**：可直接求解，或应用韦达定理（可勾选生成 `x₁+x₂`、`x₁·x₂`、`|x₁−x₂|`、判别式），结果以带注释的独立卡片呈现。
- 拖拽一张表达式卡片与另一张表达式卡片重叠时，弹出**组合窗口**：用 `A`、`B` 引用两条表达式写出新的表达式或方程，生成新卡片。
- 节点拖拽上方的操作对话框：用拖拽节点替换/加减乘除乘方目标节点，Div 节点额外支持上下同乘/同除。
- 画布级撤销/重做，覆盖添加、移动、交换、展开、变形与对话框确认。
- 全局字号滑动条；节点结构 + SymPy 表达式实时展示。

## 目录结构

```
expr_calculator/
├─ expr_tree.py                 # 表达式树、LaTeX 打印器、SymPy 互转（单文件基础模块）
├─ expr_viewer.py               # PySide6 画布应用与 HTML/MathJax 页面
├─ venv/                        # 项目虚拟环境
├─ activate.bat                 # 激活虚拟环境并进入项目目录
├─ README.md
└─ ../mathjax/                  # MathJax 已移动到项目的上一级目录
   └─ es5/
      ├─ tex-svg.js            # MathJax 3.2.x 主文件（本地，无网络依赖）
      └─ input/tex/extensions/
         ├─ color.js           # \color 扩展（层级配色需要）
         └─ html.js            # \cssId 扩展（节点 id / 点击选中需要）
```

页面中通过 `../mathjax/es5/tex-svg.js` 引用 MathJax；Python 中的检查路径为 `BASE_DIR.parent / "mathjax" / "es5" / "tex-svg.js"`。

> `color.js`、`html.js` 是本地 MathJax 的必要补丁文件：`tex-svg.js` 采用按需加载，缺少它们时 `\cssId`/`\color` 会卡住排版。**移动或拷贝项目时请连同上一级 `mathjax` 目录一起带上。**

## 使用指南

### 文本框的快捷动作（与主程序一致）

每个输入框右侧都有三个动作按钮，接线方式与 `ui/main.py` 中 `create_tab` 的做法完全相同：

| 按钮 | 图标名 | 行为 |
|---|---|---|
| 可视化输入 | `input-keyboard` | 打开 MathLive 公式编辑器（`math_input.open_formula_dialog`），返回的 LaTeX 经 `core.sympify` 转成表达式写回输入框 |
| 打开缓存区 | `document-open` | 打开 `ui.huancun.open_cache` 缓存列表，双击某一项填回输入框 |
| 存入缓存区 | `list-add` | 把当前文本去重后插到 `MainWindow.cache` 头部，图标短暂变成对勾 |

- 覆盖范围：顶部输入框、“变”对话框的表达式/换元式、常用方程的参数与条件、表达式组合、几何表达式的直线与曲线（可编辑下拉的编辑框）。
- 缓存区数据存在 `MainWindow.cache`，并在窗口上提供 `fs` 供缓存对话框复用；与主程序共用同一套 `open_cache` / `open_formula_dialog` 实现。
- 公式编辑器写回 `Eq(...)` 形式时会被自动改写为 `a = b`，以便本模块的表达式解析。

### 向画布添加表达式

- 在顶部输入框输入表达式或方程，支持 `^`、隐式乘法（`2x`、`2(x+1)`）、常见函数（`sin`、`ln`、`log`、`sqrt` 等）以及单个等号 `=`（如 `x^2=4`、`(x=y)`）。
- 输入 `(a, b)` 会作为**点卡片**加入画布（坐标可为数字或含参数的表达式，如 `(1, 2)`、`(a, b)`）。
- 按 **回车** 或点击 **添加**。
- 新卡片自动寻找不与现有卡片重叠的位置，并自动滚动到可见区域。
- 右上角显示当前表达式数量。

解析采用 `evaluate=False`，输入 `2*(x+1)` 会渲染为 `2(x+1)`，不会自动展开成 `2x+2`；输入 `x^2=4` 会渲染为自定义 `Eq` 方程节点。

### 添加常用方程

点击顶部工具栏的 **添加常用方程**，弹出三栏对话框：

- **添加方式**：「直接输入参数」或「通过条件创建」。
- **方程类型**（条件模式下称**创建对象**）：圆、直线、椭圆、双曲线、抛物线。
- **参数 / 条件**：直接输入参数时按所选形式填写，**留空表示保留该参数符号**（如圆全部留空即得 `(x−a)²+(y−b)²=r²`）；选择「通过条件创建」时右侧换成条件编辑器。

| 类型 | 形式 | 参数 |
|---|---|---|
| 圆 | `(x−a)²+(y−b)²=r²` | a、b、r |
| 直线 | `Ax+By+C=0` / `y=kx+m` | A、B、C / k、m |
| 椭圆 | `x²/a²+y²/b²=1` | a、b |
| 双曲线 | `x²/a²−y²/b²=1` / `y²/a²−x²/b²=1` | a、b |
| 抛物线 | `y²=2px` / `y²=−2px` / `x²=2py` / `x²=−2py` / `y=a(x−h)²+k` | p / a、h、k |

- 参数可填数字或表达式（如 `2*sqrt(3)`）；同一类型的参数在切换形式/类型时保留已填内容。
- 生成时会折叠纯数值：`0` 项自动省略、`1` 系数省略、数值平方算出结果（`r=3` 得到 `= 9`），符号项按模板顺序保留。
- 生成的卡片就是普通方程卡片：可拖拽、可选中节点变形、选中 `Eq` 后「变」可求解，也可与另一张方程卡片[联立求解](#方程联立求解)。
- 分母参数填 0（椭圆、双曲线的 a、b）会提示「参数取值使分母为 0」并停留在对话框。

#### 通过条件创建

左侧选 **通过条件创建**，右侧由「参数」切换为「条件」：

1. 先选方程形式；
2. 在条件下拉里挑一项，填好数值后点 **添加**，条件进入下方列表（选中可删除）；
3. 点 **确定**：每个条件被翻译成参数之间的方程，联立求解后**解出几组参数就生成几张卡片**，多张卡片算一次撤销。

可添加的条件：

| 适用范围 | 条件 | 翻译方式 |
|---|---|---|
| 通用 | 通过点 | 把 (x₀, y₀) 代入方程形式，得到参数方程 |
| 通用 | 参数关系 | 直接写参数关系，如 `a=2b`、`a+b=4`，只能含当前形式的参数 |
| 直线 | 斜率 / 截距 | 斜截式取 k、m；一般式按 `−A/B`、`−C/B` 处理 |
| 圆 | 圆心所在直线 / 半径 | 把圆心 (a, b) 代入该直线；半径即 `r=值` |
| 椭圆 | 离心率 / 长轴长 / 短轴长 / 焦距 | `e²=1−b²/a²`；长度除以 2 得半轴；`2c=焦距，c²=a²−b²` |
| 双曲线 | 离心率 / 实轴长 / 虚轴长 / 焦距 | `e²=1+b²/a²`；`2c=焦距，c²=a²+b²` |
| 抛物线 | 准线 / 焦点坐标 | 标准形式按开口方向换算 p；顶点式只有通用条件 |

示例：

| 对象 | 条件 | 结果 |
|---|---|---|
| 圆 | 圆心在 `x=1`、半径 2 | `(x−1)²+(y−b)²=4`（b 未定，保留符号） |
| 圆 | 圆心在 `x+y−2=0`、过点 (3,2)、半径 5 | 两张卡片（两组圆心） |
| 椭圆 | 离心率 `1/2`、长轴长 6 | `x²/9+4y²/27=1` |
| 双曲线 | 实轴长 6、焦距 10 | `x²/9−y²/16=1` |
| 抛物线（开口向右） | 焦点 (2,0) | `y²=8x` |

- **参数必须是实数且非退化**：离心率按类型校验（椭圆 `0 < e < 1`、双曲线 `e > 1`），轴长、焦距、半径必须为正；条件组合后若解出虚数或零半轴（如双曲线 `焦距 < 实轴长`、椭圆 `焦距 > 长轴长`），会提示「这些条件在实数范围内无解」且不生成卡片。
- **条件不足时保留参数**：如圆只给「圆心在 x=1」，结果仍是含 b 的方程族。
- **条件矛盾时提示**且不生成卡片，例如椭圆的离心率与短轴长、过点冲突。
- 求得的解会自动约分、舍弃负号重复分支（`b=±…` 代入平方后相同只出一张），直线一般式会按系数归一化成整数形式。

### 移动表达式卡片

- 每张卡片左上角有一个**红色圆形手柄**（对应第 0 层根节点）。
- 按住手柄可把卡片拖到画布内任意位置，拖动过程中允许重叠。
- 松开鼠标时检查与其它卡片的矩形重叠（保留 8px 间距）：
  - 有重叠 → **退回拖动前位置**，卡片短暂红框提示；
  - 无重叠 → 提交新位置，并记入撤销历史。
- 特例：若拖动的是**方程卡片**，且重叠对象也是**方程卡片**，回退位置后会额外弹出[方程联立求解](#方程联立求解)窗口。

### 卡片复制与删除

- 每张卡片右下角有两个小按钮：**复制**、**删除**。
- **复制**：复制当前卡片（包括右上角注释），自动寻找不重叠的位置摆放，并进入撤销历史。
- **删除**：移除当前卡片及其节点元数据；进入撤销历史，可通过撤销恢复。
- 复制/删除不会改变其它卡片；若删除的是当前选中节点所在卡片，选中状态会清空。

### 选中节点

- 点击公式中的任意节点（字符、运算符、分式线、括号内区域等）即可选中。
- 悬停时显示浅灰底，表示“点击将选中的节点”。
- 选中后：
  - 虚线框；
  - 左上角：**拖拽手柄**（把该节点拖成浮动节点）；
  - 右下角：**“变”按钮**（打开变形/操作对话框）；
  - 顶部浮动标签：节点类型 + 所在层；
  - 窗口下方：节点结构 `repr` 与转换后的 SymPy 表达式。

层级配色（由外向内循环）：

| 深度 | 颜色 |
|---|---|
| 0 | 红 |
| 1 | 绿 |
| 2 | 蓝 |
| 3 | 紫 |
| 4+ | 回到红、绿、蓝、紫 |

### 节点拖拽与重叠对话框

- 按住选中框左上角手柄拖动，会生成一个半透明的“浮动节点”（保持原颜色与排版）。
- 松手时，将浮动节点矩形与所有表达式卡片求交（**包括它自己所在的卡片**）：
  - **有重叠**：弹出“重叠的表达式”对话框，左侧以与画布相同的分层着色方式渲染被重叠的表达式；右侧是针对该表达式的操作面板；
  - **无重叠**：不弹窗，而是**以该节点为内容新建一张卡片**，落在松手的位置上（原卡片不受影响）。
- 该拖拽只是预览手势，不会把节点从原表达式里移走。

“重叠的表达式”对话框支持：

- 在左侧点击任意节点；
- 右侧选择操作（运算顺序为：**目标节点 运算 拖拽节点**）：
  - 所有节点：替换、加、减、乘、除、乘方；
  - Div 节点额外：上下同乘、上下同除；
- 点击 **确认** 后把结果写回目标卡片；点击 **取消** 不修改。
- 本次修改会进入画布撤销历史。

### “变”对话框

选中节点后点击虚线框右下角 **变**，打开变形/操作对话框。

> 特例：若选中的是方程根节点 `Eq`，则改为打开[求解方程](#求解方程)对话框；方程的左右子节点仍可使用下面的普通变形操作。

**SymPy 变形**（不需要输入表达式）：

| 方式 | 说明 |
|---|---|
| 化简 simplify | 通用化简 |
| 展开 expand | 展开括号、幂与乘积 |
| 因式分解 factor | 多项式因式分解 |
| 约分 cancel | 约去分子分母公因式 |
| 通分 together | 和式合并为单个分式 |
| 拆分 apart | 部分分式分解 |
| 三角化简 trigsimp | 三角恒等式化简 |
| 有理化 radsimp | 化简含根式的分母 |

**节点操作**（部分需要输入表达式）：

| 操作 | 结果 | 需要输入 |
|---|---|---|
| 替换 | 用输入表达式替换选中节点 | 是 |
| 追加 | 选中节点 + 输入表达式 | 是 |
| 追乘 | 选中节点 × 输入表达式 | 是 |
| 倒数 | 1 / 选中节点 | 否 |
| 除以 | 选中节点 ÷ 输入表达式 | 是 |
| 平方 | 选中节点² | 否 |
| 算术平方根 | √(选中节点) | 否 |
| 乘方 | 选中节点 ^ 输入表达式 | 是 |
| 换元 | 由换元式解出变量，把整张卡片里的变量换成新符号的表达式 | 是（符号 + 换元式） |

- 输入框支持与主输入框相同的语法（`^`、隐式乘法）。
- **换元**要填两个输入：换元符号（如 `t`）与换元式（如 `x+1`，即令 `t = x+1`）。程序从 `t = x+1` 解出 `x = t-1`，把整张卡片中的 `x` 全部替换并展开（`(x+1)²+2(x+1)+1` → `t²+2t+1`），卡片右上角记录 `t = x+1`。
- 换元式中的变量必须出现在表达式里、且能唯一解出（平方之类的多解会提示改用一次式）；换元符号不能与卡片中其它符号冲突。
- 对话框底部可选择结果去向：**覆盖原表达式**（默认）或 **保存为副本**（复制一份卡片再应用变形，原卡片保持不变，副本放在新位置）。换元同样支持这两种去向。
- 点击 **确定** 才执行；输入为空或非法时会弹出提示并停留在对话框。
- 点击 **取消** 不修改数据。

### 求解方程

输入如 `x^2 = 4` 的方程后：

1. 选中方程的根节点（`Eq` 节点，通常点击等号附近或整条方程的空白区域）；
2. 点击选中框右下角 **变**；
3. 弹出“求解方程”对话框：
   - **求解变量**：由 `free_symbols` 自动解析，例如 `x+y=2` 会列出 `x`、`y`；
   - **求解范围**：默认 `Reals`，可输入 `Complexes`、`Integers`、`Interval(0, 10)`、`S.Complexes` 等 SymPy 集合；
4. 点击 **求解**：
   - 使用 `sympy.solveset(equation, variable, domain)`；
   - 有限解集中的每个根转换为自定义表达式树，并作为一张独立卡片加入画布；
   - 多个根卡片作为一次操作进入撤销历史，撤销一次即可全部移除；
   - 无解或无限解集（如 `sin(x)=0` 在 `Reals` 上）会提示，不生成卡片。

示例：

| 输入 | 变量 | 范围 | 生成卡片 |
|---|---|---|---|
| `x^2=4` | `x` | `Reals` | `-2`、`2` |
| `x^2=4` | `x` | `Interval(0, 10)` | `2` |
| `x^2=-1` | `x` | `Complexes` | `-I`、`I` |
| `x+y=2` | `x` | `Reals` | `2 - y` |

### 添加几何表达式

顶部「添加几何表达式」按钮，选择几何量后填写点/直线/曲线：

| 几何量 | 需要 | 生成 |
|---|---|---|
| 点到直线距离 | 点 P、直线 | 表达式卡片（如 `6/5`） |
| 两直线交点 | 两条直线 | 点卡片 |
| 交点线段中点 | 直线、二次曲线 | 点卡片（以两个交点为端点的线段中点） |
| 三角形面积（三点） | 三个点 | 表达式卡片 |
| 三角形面积（直线+曲线+点） | 直线、二次曲线、点 | 表达式卡片 |

- **点输入**既可以点下拉选已有的点卡片，也可以直接输入 `(a, b)`；交点、中点生成的正是点卡片，所以能继续被后续几何计算选用。
- **直线与曲线输入同样支持选择已有卡片**：直线下拉列出所有方程卡片，曲线下拉额外列出表达式卡片（隐式方程）。也可直接输入 `Ax+By+C=0`、`y=kx+m`、`x^2/9+y^2/4=1`。
- 平行直线、直线与曲线交点不足两个、坐标格式不对时会提示且不生成卡片。
- 距离与面积用 `Abs(...)`/`sqrt(...)` 化简后落到表达式卡片上，可继续参与后续变形。

### 表达式卡片组合

把一张**表达式卡片**（非方程）拖到另一张表达式卡片上并松手：

- 两张卡片先回退到拖动前的位置；
- 弹出“组合表达式”窗口，显示 `A（被覆盖）` 与 `B（拖拽）` 两条表达式；
- 输入含 `A`、`B` 的表达式或方程（`A` 代表被覆盖的表达式，`B` 代表拖拽的表达式），如 `A+B`、`A*B`、`A=B`，窗口内实时给出预览；
- 确定后生成一张**新卡片**，两条原卡片保持不变。
- 输入只能出现 `A`、`B` 与常数；代入采用结构化替换（不做化简），需要整理可再点「变 → 化简」。

### 方程联立求解

把一张**方程卡片**拖到另一张**方程卡片**上并松手：

- 两张卡片先按非重叠规则回退到拖动前位置；
- 随后弹出“联立方程”窗口，显示两条方程与全部自由变量；
- 可选择一种模式：
  - **直接求解**：勾选需要求解的自由变量，调用 `sympy.solve(..., dict=True)`；每个解对象里的每个变量赋值生成一张 `变量名 = 根` 方程卡片，并在右上角标注“解 1 / 解 2 …”；
  - **应用韦达定理**：不限制自由变量总数；只勾选一个**主变量**即可。含参方程中的参数（如 `a`、`b`、`c`）会被当作系数保留，`x/y/z` 等变量则优先通过 `sympy.resultant` 消去。程序会从原方程或消元结果中提取关于主变量的二次多项式 `a·x² + b·x + c`，然后按下方勾选项生成卡片：

    | 勾选项 | 计算 | 卡片注释 |
    |---|---|---|
    | `x₁ + x₂` | `-b/a` | `x₁ + x₂` |
    | `x₁·x₂` | `c/a` | `x₁·x₂` |
    | `|x₁ − x₂|` | `√Δ / |a|` | `|x₁ − x₂|` |
    | 判别式 Δ | `b² − 4ac` | `Δ` |

    默认只勾选前两项；一个都不勾会提示。注释放的是主变量名（如主变量为 `t` 时为 `t₁ + t₂`）。
    - 默认自动选择二次项最明显的主变量，可手动改选；切换到此模式时会自动只保留一个勾选变量。
- 多张结果卡片合并为一次撤销历史，撤销一次即可全部移除。
- 直接求解无解、韦达定理无法提取出关于主变量的二次多项式时会提示，不生成卡片。

示例（联立 `x + y = 3` 与 `x*y = 2`）：

| 模式 | 勾选变量 | 生成卡片 |
|---|---|---|
| 直接求解 | `x`、`y` | `x = 1`、`y = 2`、`x = 2`、`y = 1` |
| 韦达定理 | `x` | `3`（标注 `x₁ + x₂`）、`2`（标注 `x₁·x₂`） |

含参示例（参数同样出现在自由变量列表中）：

| 方程 | 勾选主变量 | 生成卡片 |
|---|---|---|
| `x^2 - a*x + b = 0` 与 `y = 0` | `x` | `a`（标注 `x₁ + x₂`）、`b`（标注 `x₁·x₂`） |
| `x + y = a` 与 `x*y = b` | `x` | `a`（标注 `x₁ + x₂`）、`b`（标注 `x₁·x₂`） |
| `x^2 + y = c` 与 `y = d` | `x` | `0`（标注 `x₁ + x₂`）、`d - c`（标注 `x₁·x₂`） |

### 卡片折叠

- 每张卡片右下角有 **复制 / 删除 / 折叠** 三个按钮；点“折叠”后卡片收紧成一行。
- 折叠态仍然**排版渲染公式**，但样式简化为单色黑（不再分层着色）、无阴影、字号约为正常的 0.66 倍（默认 42px → 27.7px），**仍跟随字号滑块缩放**；标题、换元注释与“展开”按钮改为内联排列。
- 折叠卡片**没有任何交互**：不安装命中区、不生成悬停徽标，点不出节点选中框。
- 展开时重新排版并恢复节点交互。
- 折叠不进入撤销历史；撤销/重做重建卡片时会保留折叠状态，复制卡片也会继承。

### 卡片标题

- 卡片顶部有一行标题，空标题显示浅灰提示「双击设置标题」。
- **双击标题**即变成小文本框：回车或点击别处提交，Esc 取消；标题会同步到属性区。
- 折叠状态下标题改为内联显示在公式前，空标题时不占位。
- 标题随卡片复制、撤销/重做保留（不进入撤销历史）。

### 属性区

- 选中节点会高亮**所在卡片**（蓝色描边 + 外发光）；点击卡片空白处或折叠卡片的正文则选中整张卡片（同样高光）。
- 属性面板显示：标题、表达式、变量、**取值范围**（对单变量表达式调用 `sympy.calculus.util.function_range`，区间以 `[a, b]` 形式展示）。
- 暂不支持的取值：方程卡片提示「方程暂无取值范围」，多变量提示「含多个变量，暂不支持」，运算符数超过 60 的表达式提示「较复杂，暂不计算」。
- 面板与画布之间有分隔条，可拖动改变宽度（150–520 px），默认 220 px。

### 字号与详情面板

- 页面右上角滑块调整整个画布字号（默认 42px），所有卡片同步缩放。
- 窗口下方详情区显示：`节点结构：...` 与 `SymPy：...`。

### 撤销与重做

- 顶部按钮：**撤销 / 重做**。
- 快捷键：`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- 历史记录为**整张画布快照**（卡片集合、表达式树、位置），包含：
  - 添加表达式；
  - 卡片拖拽落位；
  - 加号交换、括号展开；
  - 选中节点化简/变形；
  - 节点拖拽对话框中的确认操作；
  - 卡片复制、删除；
  - 联立窗口的直接求解 / 韦达定理结果卡片（一次操作合并记录）。
- 调整字号、选中节点不会进入历史；撤销后选中状态会清空。
- 新添加表达式会截断当前重做分支。

## 工作原理

```
输入字符串
   │ parse_sympy(evaluate=False)
   ▼
SymPy 表达式（保留输入顺序与括号）
   │ from_sympy(ordered=False)
   ▼
自定义表达式树 Expr
   │ LatexPrinter(colorize=True, id_prefix="c1__")
   ▼
带 \cssId 的 LaTeX + node_info/node_map
   │ MathJax tex-svg.js
   ▼
SVG（点击/悬停命中矩形由 JS 后处理添加）
```

- 输入包含顶层等号（如 `x=y`、`(x^2=4)`）时，`parse_sympy` 先拆成左右两式，返回 `sympy.Eq(..., evaluate=False)`，再转换为自定义 `Eq` 节点。
- 每个节点被包上 `\cssId{c1__l{层}-n{序号}}{...}`，层色通过 CSS 选择器 `g[id*="__l0-"]` 等控制。
- MathJax 排版完成后，JS 为每个节点插入透明命中矩形，并生成交互用的操作命中层。
- 画布与对话框通过 `QWebChannel` 和 Python 通信（选中、交换、展开、拖拽、变形、确认等）。

## 表达式树模块 `expr_tree`

单文件模块，无第三方依赖（除 SymPy），可直接在其他项目中使用。

### 节点体系

```
Expr
├─ Atom
│  ├─ Symbol       # 符号
│  ├─ Integer      # 整数
│  ├─ Rational     # 有理数（分母为 1 时自动变为 Integer）
│  ├─ Float        # 浮点数
│  └─ Constant     # pi / E / I / oo / zoo / NaN / True / False
├─ NaryOp
│  ├─ Add          # 多参数加法
│  ├─ Mul          # 多参数乘法
│  ├─ Pow          # 双参数幂
│  ├─ Div          # 双参数分式
│  ├─ Eq           # 双参数方程：left = right
│  ├─ Derivative   # 导数：表达式 + 变量/阶数
│  ├─ Integral     # 积分：被积函数（+ 上下限）
│  ├─ Piecewise    # 分段函数：（表达式, 条件）成对
│  ├─ Relational   # 关系式：< <= > >= !=
│  ├─ LogicalOp    # 逻辑连接：and / or / not
│  └─ FiniteSet    # 有限集：{a, b, c}
└─ Function
   ├─ Sin Cos Tan Cot Sec Csc
   ├─ Asin Acos Atan Acot
   ├─ Sinh Cosh Tanh
   ├─ Exp Ln Log Abs Sign Factorial
   └─ 动态生成的未知函数（如 f、besselj）
```

### 关键约定

- **顺序即语义**：多参数节点严格按传入顺序保存参数。
- **父指针**：子节点保存 `parent`；把已有节点放入新父节点时会自动复制，保证一棵树内引用唯一。
- **Pow 负整数指数**：`Pow(x, -2)` 自动转换为 `Div(1, Pow(x, 2))`。
- **Div 分母为零**：构造时对数值零分母抛 `ZeroDivisionError`。
- **Div 是显式分式节点**：`2*x/3` 转换后是 `Div(Mul(2, x), 3)`，而不是带分数系数的 `Mul`。
- **Eq 是显式方程节点**：`x=y` 转换为 `Eq(Symbol("x"), Symbol("y"))`；`left` / `right` 对应左右两式，`to_sympy()` 返回 `sympy.Eq(..., evaluate=False)`，LaTeX 渲染为 `左式 = 右式`。
- **Derivative / Integral 带元数据**：变量名与阶数保存在节点上（`variables` / `variable`），不占子节点；定积分的上下限是子节点，可直接选中改动。
- **Piecewise 成对保存**：`args` 为 `(表达式, 条件)` 序列，必须是偶数个；SymPy 的 `True` 条件渲染为 `otherwise`，不单独生成节点 id。
- **Relational 覆盖 5 种关系**：`<` `<=` `>` `>=` `!=`；等式仍由 `Eq` 表示，两者不会混用。
- **LogicalOp 承载布尔连接**：`and` / `or` 多元，`not` 一元；`simplify` 合并分段条件时会自动得到这类节点。
- **FiniteSet 允许空集**：`FiniteSet()` 对应 SymPy 的 `EmptySet`，LaTeX 渲染为 `\varnothing`。

### 构造与修改

```python
from expr_tree import Add, Mul, Div, Pow, Eq, Symbol, Integer

x, y = Symbol("x"), Symbol("y")

add = Add(x, y, Integer(1))
add.swap(0, 2)          # 参数顺序交换
add.insert(1, Symbol("z"))
add.replace(0, Integer(2))
add.remove(2)

node = Mul(x, Add(y, Integer(1)))
node.args[1].swap(0, 1) # 直接操作子节点

equation = Eq(Add(x, Integer(1)), y)
print(equation.left, equation.right, equation.to_sympy())
```

常用属性：`args`、`children`、`parent`、`root`、`index_in_parent`、`free_symbols`、`depth()`、`size()`。

### 遍历与改写

```python
tree.walk("pre")        # 先序/后序遍历
tree.nodes()            # 所有节点
tree.leaves()           # 叶子节点
tree.find(lambda n: n.is_number)
tree.find_all(lambda n: type(n).__name__ == "Div")
tree.subs(x, Integer(2))
tree.transform(lambda n: n)   # 自底向上重建
```

### SymPy 互转

```python
import sympy
from expr_tree import from_sympy, from_string, parse_sympy

expression = parse_sympy("2*(x+1)")     # evaluate=False，保留括号
tree = from_sympy(expression, ordered=False)

equation = parse_sympy("x^2=4")         # 返回 sympy.Eq，保留左右两边
eq_tree = from_sympy(equation, ordered=False)

tree2 = from_string("(x+1)/(x-1)")      # 解析 + 转换
back = tree2.to_sympy()                 # 回到 SymPy
sympy.sympify(tree2)                    # 也支持 _sympy_
```

- `from_sympy(expr, ordered=True)` 默认按 SymPy 显示顺序排列；
- `ordered=False` 保留传入表达式的参数顺序（配合 `evaluate=False` 使用）。

### LaTeX 生成

```python
from expr_tree import LatexPrinter, color_latex

print(tree2.latex())                     # 普通 LaTeX
latex_code, info = color_latex(tree2)    # 分层着色 + 节点信息

printer = LatexPrinter(colorize=True, id_prefix="c1__")
code = printer.doprint(tree2)
print(printer.node_info)                 # id -> {type, depth, color, text, parent, expandable}
print(printer.node_map)                  # id -> 节点对象
```

支持分式、根式、三角函数幂、绝对值、阶乘、对数、`e^x`、希腊字母、下标、负数项等。

结构节点的渲染方式：

| 节点 | LaTeX | 说明 |
|---|---|---|
| `Derivative` | `\frac{\mathrm{d}}{\mathrm{d}x}\left(...\right)` | 二阶为 `\mathrm{d}^{2}/\mathrm{d}x^{2}`，多变量转偏导 `\partial` |
| `Integral` | `\int_{0}^{1} ...\,\mathrm{d}x` | 不定积分省略上下限，多重积分按嵌套渲染 |
| `Piecewise` | `\begin{cases} ... & \text{if }... \\ ... & \text{otherwise}\end{cases}` | 每行与条件分别着色 |
| `Relational` | `\lt` `\le` `\gt` `\ge` `\ne` | 左右两侧均可点选 |
| `LogicalOp` | `\land` `\lor` `\lnot` | 运算符优先级不同的子句自动加括号 |
| `FiniteSet` | `\left\{ ... \right\}` | 空集为 `\varnothing` |

> `\cssId` 包住 `cases` 环境、把 `cases` 作幂底数（`\left(...\right)^{2}`）在本地 MathJax 3.2 上均已验证可用。

### 结构操作

```python
from expr_tree import Div, Integer, Symbol

f = Div(Integer(1), Symbol("x")).add(Div(Integer(1), Symbol("y")))
print(f)              # (y + x)/(x*y)
print(f.reduce())     # 约分

from expr_tree import from_string

from_string("2*(x+1)").expand()   # 2*x + 2
from_string("(x+1)^2").expand()  # x**2 + 2*x + 1
tree.simplify()                   # 交给 SymPy simplify
```

> `Div.reduce()` 只做**结构约分**（相同因式、数值公因数），不做多项式因式分解；需要多项式化简时用 `simplify()`。

## 设计约定与限制

1. **括号保留依赖 `evaluate=False`**：`2*(x+1)` 会保留；但 SymPy 解析器对一元负号仍会分配，例如 `-(x+1)` 会变为 `-1 - x`。
2. **非重叠约束只在卡片拖拽松手时强制**：展开、变形或调大字号使卡片尺寸变化时，不会自动重新排布其它卡片。
3. **撤销历史为全画布快照**：数据量随卡片数量增长；选中状态、字号不在历史内。
4. **对话框操作作用于被重叠的那张卡片**；节点拖拽本身不改变原树。
5. **节点 id 带前缀**（如 `c1__l0-n3`），因此多张卡片同屏时 `\cssId` 不冲突。
6. **MathJax 位于项目上一级目录** `../mathjax/`，不依赖网络；必须保留 `color.js` 与 `html.js`。
7. 画布固定为 2200×1400 的可滚动区域，卡片位置限制在画布内。
8. **方程求解只展开有限解集**：`solveset` 返回 `ImageSet`、`ConditionSet`、区间等无限集合时提示，不创建卡片；`Intersection` 中的有限候选根会被提取。
9. **联立窗口的韦达定理**不限制自由变量数量，但要求只勾选一个主变量，且能从方程或消元结果中提取出关于该变量的二次多项式；更高次、非多项式系统或无法消元的情况会提示，不生成韦达卡片。`x/y/z` 等变量优先消元，`a/b/c` 等符号默认作为参数保留。
10. **节点 id 与树节点不是严格 1:1**：隐式系数（如 `-x` 的 `-1`）与 `Piecewise` 的 `True` 条件为纯排版产物，不生成独立 id，因此这两类节点无法单独点选。
11. **类型覆盖面**：已支持 Symbol / Integer / Rational / Float / Constant / Add / Mul / Pow / Eq / Derivative / Integral / Piecewise / Relational / And / Or / Not / FiniteSet / 各类函数节点；`ImageSet`、`ConditionSet`、`Union`、`Matrix`、`RootOf`、`Sum`、`Limit` 仍未支持，遇到时会在状态栏或对话框提示“不支持的 SymPy 类型”。
12. **画布排版按卡片串行**：MathJax 排版通过页面内队列串行执行，批量添加（求解多根、联立结果）不会出现排版错乱，但会按顺序逐个完成。

## 常见问题

**公式不显示 / 只有白屏**

检查上一级目录 `../mathjax/es5/tex-svg.js` 是否存在；若 `\cssId` 相关页面卡住，检查：

```
../mathjax/es5/input/tex/extensions/color.js
../mathjax/es5/input/tex/extensions/html.js
```

**节点没有颜色**

确认 `mathjax` 扩展文件存在，且页面 CSS 中的 `g[id*="__l0-"]` 等规则未被覆盖。

**QWebEngineView 启动异常 / 黑屏**

部分环境需要关闭 GPU：

```bat
set QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu
```

程序已在创建 `QApplication` 前设置 `Qt.AA_ShareOpenGLContexts`。

**中文在离屏截图中显示为方块**

这是离屏平台缺少中文字体导致；正常 Windows 桌面运行时不受影响。

**SymPy 化简/变形没有按预期改变**

“变”对话框使用 SymPy 对应函数直接作用于选中子树；例如 `factor` 只做因式分解，不会自动约分，可再选择 `cancel` 或 `simplify`。
