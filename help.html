示例：2*x、x**2、sqrt(x)、log(x,2)、log(x)、sin(x)。

LaTeX 直接输入

表达式前加半角美元符号 $ 即可直接写 LaTeX，例如 $\frac{x}{2} → x/2、$x^{2} → x**2、$\sqrt{x} → sqrt(x)、$\int_{0}^{1} x^2 \mathrm{d}x。

必须以半角 $ 开头，否则按 SymPy / Python 语法解析；两种写法可在同一表达式中混用。

集合常用于「函数定义域」「求解范围」等输入框，例如 FiniteSet(0,1) 限定只取离散根，ImageSet(Lambda(n, n*pi), Integers) 表示 sin(x)=0 的通解。

自定义函数与微分方程

  • 自定义函数：在定义区定义后即可在其它输入框使用——作符号参与运算（已定义 g=x**2 时输入 g+1/g），或调用传参：f(3)、嵌套 f(g(2))。
  • 微分方程：待解函数固定为 f(x)，用 f(x).diff(x,n) 表示 n 阶导数（n 可省略）。例：左式 f(x).diff(x)、右式 f(x)+1，解为 f(x)=C1*exp(x)-1。

三、向量与解三角形

向量（定义区 → 向量）：填写名称与 x / y 分量（支持 sqrt(3)、pi/2 等表达式）后保存；可查看表达式、模、方向角、单位向量，并可做加法、减法、点积与夹角运算。

解三角形（计算区 → 解三角形）：从角 A/B/C、边 a/b/c 中给出恰好 3 个条件，支持五种情形：

情形已知解的个数
ASA / AAS两角一边（夹边 / 对边）唯一解
SAS两边及夹角唯一解
SSA两边及其中一边对角可能两解、一解或无解（自动标注"解1""解2"）
SSS三边唯一解

四、函数绘图

绘图区选「函数模式」：直接输入表达式（如 sin(x)），或勾选定义区已定义的函数；设置定义域左右端点（默认 [-10, 10]，支持表达式），点击绘制or更新。图像由 Matplotlib 渲染，自动处理间断点（如 1/x 在 0 处断开），y 轴自适应可见范围，并支持放缩、拖动与保存。

七、解几计算器

通过菜单"功能 → 解几计算器"打开表达式画布：表达式、方程与点都以卡片形式摆放，公式按表达式树深度着色（红 → 绿 → 蓝 → 紫，四层循环），任意子结构都能点选、拖拽、变形或求解。

  • 顶部工具栏：输入框与「添加」、表达式计数、添加几何表达式、添加常用方程、撤销 / 重做。
  • 画布：卡片自由摆放，右上角滑块调整字号（默认 42px）。
  • 属性区（右）：所选卡片的标题、表达式、变量与取值范围，宽度可拖动（150–520px）。
  • 详情区（下）：选中节点的树结构与 SymPy 表达式。

添加与选中

  • 输入表达式或方程后按回车或点「添加」；输入 (a, b) 生成点卡片。解析保留输入顺序与括号（2*(x+1) 不会自动展开）。
  • 点击公式中任意节点即可选中：出现虚线框、左上角拖拽手柄、右下角「变」按钮与"类型 · 第 N 层"标签。
  • 点击加法项之间的 + / −（或悬停徽标「⇄ 交换」）交换相邻项；点击括号（或「⤢ 展开」）展开乘积与乘方。

「变」对话框

选中节点后点右下角变。若选中的是方程根节点，则改为打开求解对话框。

SymPy 变形（无需输入）节点操作
化简、展开、因式分解、约分、通分、拆分、三角化简、有理化替换、追加、追乘、倒数、除以、平方、算术平方根、乘方、换元
（替换 / 追加 / 追乘 / 除以 / 乘方 / 换元需输入表达式）

结果可选择覆盖原表达式（默认）或保存为副本。换元需填符号（如 t）与换元式（如 x+1，即 t = x+1），程序解出 x 后代换整张卡片并展开，卡片右上角记录该关系。

节点拖拽与求解

  • 拖动手柄生成浮动节点：拖到空白处新建卡片；拖到卡片上弹出「重叠的表达式」，按目标节点 运算 拖拽节点执行（分式节点另有上下同乘 / 同除）。
  • 两张表达式卡片重叠 → 「组合表达式」，用 A（被覆盖）、B（拖拽）写出 A+B、A*B、A=B 等。
  • 两张方程卡片重叠 → 「联立方程」：直接求解（按勾选变量生成"变量 = 根"卡片）或应用韦达定理（只勾一个主变量，生成 x₁+x₂、x₁·x₂、|x₁−x₂|、判别式卡片）。
  • 求解方程：选方程根节点 → 变 → 选变量与范围（SymPy 集合，默认 Reals）→ 求解，每个根生成一张卡片；解集无限时只提示不生成。

常用方程与几何表达式

添加常用方程支持五种模板；参数可填数字或表达式，留空表示保留该参数符号：

类型形式参数
圆(x−a)²+(y−b)²=r²a、b、r
直线Ax+By+C=0 / y=kx+mA、B、C / k、m
椭圆x²/a²+y²/b²=1a、b
双曲线x²/a²−y²/b²=1 / y²/a²−x²/b²=1a、b
抛物线y²=2px / y²=−2px / x²=2py / x²=−2py / y=a(x−h)²+kp / a、h、k

左侧选「通过条件创建」还可反推参数：通用条件有通过点与参数关系；各类型另有专属条件——直线（斜率、截距）、圆（圆心所在直线、半径）、椭圆与双曲线（离心率、轴长、焦距）、抛物线（准线、焦点坐标，仅标准形式）。解出几组参数就生成几张卡片；条件不足时保留参数，矛盾或实数范围无解时给出提示。

添加几何表达式：点到直线距离、两直线交点、交点线段中点、三角形面积（三点 / 直线+曲线+点）。点、直线、曲线可下拉选择已有卡片，也可直接输入（(2, 3)、y=x+1、x^2/9+y^2/4=1），结果仍是可继续变形的卡片。

卡片与撤销

  • 拖拽左上角红色手柄移动卡片；松开时若与其它卡片重叠（8px 间距）则退回原位并短暂红框提示。
  • 右下角三个按钮：复制、删除、折叠（折叠后仍渲染公式，但不再响应节点交互）。
  • 双击标题行可编辑，回车提交、Esc 取消；属性区显示标题、表达式、变量与取值范围。
  • 顶部「撤销 / 重做」或 Ctrl+Z / Ctrl+Y 回退整张画布快照；调整字号与选中节点不进入历史。
  • 界面支持中英文；在设置页切换语言后画布即时刷新并保留全部卡片。主题随主窗口浅色 / 深色自动切换，卡片、公式分层配色、滚动条一并同步，无需重新添加卡片。公式由内置 MathJax 渲染，无需联网。

八、效率工具

缓存区

通过"文件 → 缓存区"打开缓存区标签页，展示所有已缓存表达式，双击可复制到剪贴板。每个输入框右侧另有三个快捷按钮：

按钮功能说明
键盘可视化输入打开公式编辑器，图形化插入数学符号
打开打开缓存区弹出缓存列表，双击填入当前输入框
加号存入缓存区存入当前文本（重复项置顶，图标短暂变对勾）

可视化公式输入

基于 MathLive（内置于 math_input/）的公式面板：点击输入框右侧键盘图标打开，通过工具栏选择结构（分式、根号、上下标、括号）、希腊字母、运算符与常用函数，点确定后自动转换为 SymPy 表达式填入输入框。

九、设置与存档

通过"文件 → 设置"打开设置页：界面语言（中文 / English）、界面主题（浅色 / 深色）均即时生效并持久化，下次启动自动恢复；帮助页会随语言自动切换中 / 英文档。设置以 JSON 保存在 AppData/Local/CalculusCalculator/CalculusCalculator/settings.json。

存档设置可控制保存时写入哪些数据（默认全选）：

类别包含内容
数据函数列表、方程 / 不等式列表、向量列表、缓存区内容
几何平面几何对象、立体几何对象
界面所有文本框文本、选择框选项、公式显示框内容、标签页序号 / 语言 / 主题等设置

取消勾选的类别不写入存档；读档时存档中缺少该类别则保持当前状态。工程文件后缀为 .cca（JSON），双击即可打开并恢复现场。

十、积木编辑器与启动

通过"功能 → 编辑器"打开积木编辑器，拖拽拼接积木即可搭建可视化计算流程，无需写代码：

  • 支持 SymPy 表达式与 $ 前缀 LaTeX 输入，点击运行按顺序执行并实时显示中间结果与 LaTeX 渲染。
  • 覆盖定义函数、函数性质分析、求导 / 积分、解方程（组）、解不等式（组）、解三角形等。
  • 代码预览双模式：可切换查看原生 SymPy 代码（仅依赖 SymPy，可复制到任意解释器运行）与库代码（运行按钮实际执行的代码），默认前者。
  • 工程可存档 / 读档，受「存档设置」控制。

启动：启动时显示轻量启动画面；QWebEngine 内核改为首次打开积木编辑器、公式输入或解几计算器时才初始化，配合懒加载加快启动。
