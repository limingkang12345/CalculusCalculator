    解几计算器（v2.2.0）

    表达式画布是 v2.2.0 新增的标签页，把解析几何中的表达式、方程与点都表示为可拖动、可点选的卡片，公式按表达式树深度分层着色，任意子结构都能就地变形或求解。

    通过菜单"功能 → 解几计算器"打开，源码位于 expr_calculator/：

    文件 作用
    expr_tree.py 表达式树、LaTeX 打印器与 SymPy 互转（不依赖 Qt）
    expr_viewer.py 画布窗口、HTML/MathJax 页面与各操作对话框
    ../ui/expr.py 标签页包装，提供 retranslateUi 供语言切换联动

    快速上手

    1. 在顶部输入框输入 2*(x+1) + 1/(x-1)，按 回车 或点击 添加，表达式成为一张卡片；
    2. 点击公式中的任意节点（字符、运算符、分式线、括号内区域）选中它；
    3. 点击选中框右下角的 变 打开变形对话框；
    4. 拖动卡片左上角的红圈可移动卡片。

    解析采用 evaluate=False，输入顺序与括号会保留（2*(x+1) 不会自动展开）。

    输入能力

    输入 结果
    x^2=4、x=y 方程卡片（Eq 节点），可求解与联立
    (a, b) 点卡片（坐标可为数字或含参数的表达式）
    sin(x)、ln(x)、sqrt(x) 函数节点
    2x、2(x+1) 隐式乘法

    节点级操作

    操作 方式
    选中节点 点击公式中的节点，悬停显示浅灰底
    交换相邻项 点击 + / −，或悬停徽标"⇄ 交换"
    展开括号 点击括号，或悬停徽标"⤢ 展开"
    拖动节点 选中框左上角手柄；拖到空白处新建卡片，拖到卡片上弹出运算对话框
    变形 选中框右下角"变"

    "变"对话框提供 8 种 SymPy 变形（simplify / expand / factor / cancel / together / apart / trigsimp / radsimp）与 9 种节点操作（替换、追加、追乘、倒数、除以、平方、算术平方根、乘方、换元），结果可覆盖原表达式或保存为副本。

    换元

    选择"换元"后填写符号（如 t）与换元式（如 x+1，即令 t = x+1）。程序解出 x = t-1，把整张卡片中的 x 全部代换并展开。

    常用方程与条件反推

    "添加常用方程"支持圆、直线、椭圆、双曲线、抛物线五种模板：

    • 直接输入参数：留空表示保留该参数符号（圆全部留空即得 (x−a)²+(y−b)²=r²）；
    • 通过条件创建：用"通过点 / 参数关系 / 斜率 / 截距 / 圆心所在直线 / 半径 / 离心率 / 轴长 / 焦距 / 准线 / 焦点坐标"等条件联立求解参数，解出几组参数就生成几张卡片。

    Example

    圆心在 x=1、半径 2 → (x−1)²+(y−b)²=4（b 未定，保留符号）
    椭圆离心率 1/2、长轴长 6 → x²/9+4y²/27=1
    双曲线实轴长 6、焦距 10 → x²/9−y²/16=1

    几何表达式

    几何量 生成
    点到直线距离 表达式卡片
    两直线交点 点卡片
    交点线段中点 点卡片
    三角形面积（三点 / 直线+曲线+点） 表达式卡片

    点、直线、曲线既可下拉选择已有卡片，也可直接输入（(2, 3)、y=x+1、x^2/9+y^2/4=1）。结果仍是普通卡片，可继续参与变形或几何计算。

    方程求解与联立

    • 求解方程：选中方程根节点 → "变" → 选变量与求解范围（SymPy 集合，默认 Reals）→ 求解，每个根生成一张卡片；
    • 联立求解：把一张方程卡片拖到另一张上，可选直接求解（勾选自由变量，生成"变量名 = 根"卡片）或应用韦达定理（勾选一个主变量，生成 x₁+x₂、x₁·x₂、|x₁−x₂|、判别式卡片）。

    卡片与画布

    • 卡片支持移动（重叠自动回退）、复制、删除、折叠（折叠后不再响应节点交互）、双击设置标题；
    • 右侧属性区显示标题、表达式、变量与取值范围；
    • 顶部 撤销 / 重做 或 Ctrl+Z / Ctrl+Y 回退整张画布快照；
    • 右上角滑块调整整张画布字号。

    多语言

    解几计算器的全部界面文案（工具栏、对话框、状态提示、画布按钮与悬停提示）均已接入 Qt 翻译体系，翻译上下文为 expr_calculator。在"设置"页切换语言后：

    • 画布会以新语言重新加载页面；
    • 已有卡片按原位置、标题、注释与折叠状态完整重建，不会丢失。

    新增文案的流程与主程序一致，详见《国际化》。

    渲染说明

    公式由项目内置的本地 MathJax（mathjax/es5/tex-svg.js）渲染，无需联网。页面以 ../mathjax/ 相对路径引用，请勿单独移动 mathjax 目录；打包时 setup.py 会把 expr_calculator/ 与 mathjax/ 一并放入 lib/。
