7 kinds of tabs: Home, All-in-One, Help, Settings, Cache, Blockly Editor, Expression Calculator. Several tabs of the same kind can be open at once (titles are numbered automatically); tabs can be closed and reordered by dragging.

The All-in-One page is the main workspace, divided left to right into three areas with draggable splitters:

  1. Define area: pick a type (Function / Set / Vector / Plane Geometry / Solid Geometry) and define functions and objects, grouped by type in a tree list.
  2. Compute area: pick a computation type (Compute, Derivative, Integral, Equation, Inequality, System of Equations, System of Inequalities, Plane Compute, Solid Compute, Transform, Solve Triangle — 11 in total).
  3. Plot area: pick a mode (Plane Geometry / Solid Geometry / Function), check objects and click Plot or Update.
Enter shortcut: pressing Enter in the main input boxes triggers the corresponding button (e.g. "Compute", "Save"), so no mouse click is needed.

Direct LaTeX input

Prefix an expression with a half-width dollar sign $ to write LaTeX directly, e.g. $\frac{x}{2} → x/2, $x^{2} → x**2, $\sqrt{x} → sqrt(x), $\int_{0}^{1} x^2 \mathrm{d}x.

It must start with a half-width $; otherwise the expression is parsed as SymPy / Python syntax. Both styles can be mixed in one expression.

Sets are used for inputs such as function domains and solve ranges, e.g. FiniteSet(0,1) restricts roots to those points, and ImageSet(Lambda(n, n*pi), Integers) is the general solution of sin(x)=0.

Custom functions and differential equations

  • Custom functions: once defined in the Define area they can be used anywhere — as a symbol (with g=x**2, entering g+1/g) or called with arguments: f(3), nested f(g(2)).
  • Differential equations: the unknown function is fixed to f(x); write f(x).diff(x,n) for the n-th derivative (n optional). Example: left f(x).diff(x), right f(x)+1 gives f(x)=C1*exp(x)-1.

3. Vectors and Triangle Solving

Vectors (Define area → Vector): enter a name and the x / y components (expressions such as sqrt(3) or pi/2 are accepted) and save. You can inspect the expression, norm, direction angle and unit vector, and compute addition, subtraction, dot product and angle.

Triangle solving (Compute area → Solve Triangle): give exactly 3 conditions among angles A/B/C and sides a/b/c. Five cases are supported:

CaseGivenSolutions
ASA / AASTwo angles and one side (included / opposite)Unique
SASTwo sides and the included angleUnique
SSATwo sides and a non-included angleTwo, one or none (labelled "Solution 1", "Solution 2")
SSSThree sidesUnique

4. Function Plotting

In the Plot area choose "Function mode": type an expression (e.g. sin(x)) or check a function defined in the Define area, set the domain endpoints (default [-10, 10], expressions allowed) and click Plot or Update. Graphs are rendered by Matplotlib, discontinuities are handled automatically (e.g. 1/x breaks at 0), the y-axis scales to the visible range, and zooming, panning and saving are supported.

5. Plane / Solid Geometry

In the Define area choose "Plane Geometry" or "Solid Geometry", then pick a creation method, fill in the object name and the parameters (separated by half-width commas), and press Enter or click Save. Parameters refer to the names of already defined objects.

7. Expression Calculator

Open the expression canvas via "Features → Expression Calculator": expressions, equations and points are laid out as cards, formulas are colored by expression-tree depth (red → green → blue → purple, cycling every four levels), and any sub-structure can be selected, dragged, transformed or solved.

  • Toolbar: input box and "Add", expression counter, Add geometric expression, Add common equation, Undo / Redo.
  • Canvas: cards are placed freely; the slider at the upper right scales the font (42px by default).
  • Properties (right): title, expression, variables and range of the selected card; the splitter is draggable (150–520px).
  • Detail pane (bottom): tree structure and SymPy expression of the selected node.

Adding and selecting

  • Type an expression or equation and press Enter or click "Add"; entering (a, b) creates a point card. Input order and parentheses are preserved (2*(x+1) is not expanded).
  • Click any node in a formula to select it: a dashed box, the drag handle at the upper left, the "Transform" button at the lower right and a "type · depth" tag appear.
  • Click + / − between additive terms (or the "⇄ Swap" badge) to swap them; click parentheses (or "⤢ Expand") to expand products and powers.

The "Transform" dialog

Select a node and click Transform. If the node is the root of an equation, the solve dialog opens instead.

SymPy transforms (no input)Node operations
Simplify, expand, factor, cancel, together, apart, trig simplify, rationalizeReplace, append, multiply, reciprocal, divide, square, square root, power, substitution
(replace / append / multiply / divide / power / substitution need an expression)

Results can overwrite the original expression (default) or be saved as a copy. Substitution takes a symbol (e.g. t) and an expression (e.g. x+1, i.e. t = x+1); the program solves for x, replaces it in the whole card and expands, recording the relation at the card's upper right.

Dragging nodes and solving

  • Dragging the handle creates a floating node: drop it on empty canvas to create a card, or on a card to open "Overlapping expression" and apply target node operation dragged node (fraction nodes also support multiply-both / divide-both).
  • Two expression cards overlapping → "Combine expressions": use A (covered) and B (dragged) to write A+B, A*B, A=B, etc.
  • Two equation cards overlapping → "System of equations": solve directly (one "variable = root" card per ticked variable) or Vieta's formulas (tick one main variable; cards for x₁+x₂, x₁·x₂, |x₁−x₂| and the discriminant).
  • Solve equation: select the equation root → Transform → choose variable and domain (a SymPy set, Reals by default) → Solve; each root becomes a card, and an infinite solution set only produces a message.

Common equations and geometric expressions

Add common equation offers five templates; parameters accept numbers or expressions, and a blank field keeps its symbol:

Choosing Create from conditions on the left derives the parameters instead: general conditions are through point and parameter relation; each type adds its own — line (slope, intercept), circle (line through the center, radius), ellipse and hyperbola (eccentricity, axis lengths, focal distance), parabola (directrix, focus — standard forms only). Every solution set produces a card; insufficient conditions keep the parameters, while conflicting or non-real conditions are reported.

Add geometric expression: point-line distance, intersection of two lines, midpoint of the intersection segment, triangle area (three points / line + conic + point). Points, lines and curves can be picked from existing cards or typed directly ((2, 3), y=x+1, x^2/9+y^2/4=1); results remain fully transformable cards.

Cards and undo

  • Drag the red handle at a card's upper left to move it; on release, an overlap with another card (8px margin) sends it back with a short red border.
  • Three buttons at the lower right: Copy, Delete, Fold (folded cards still typeset the formula but no longer respond to node interaction).
  • Double-click the title row to edit it (Enter commits, Esc cancels); the properties panel shows title, expression, variables and range.
  • Toolbar Undo / Redo or Ctrl+Z / Ctrl+Y steps through whole-canvas snapshots; font size and selection are not recorded.
  • The interface is bilingual; switching the language in Settings refreshes the canvas while keeping every card. The theme follows the light / dark setting of the main window — cards, layered formula colors and scrollbars update in place without re-adding anything. Formulas are rendered by the bundled MathJax, no network needed.

9. Settings and Saving

Open Settings via "File → Settings": interface language (Chinese / English) and theme (light / dark) apply immediately and are persisted for the next launch; the help page follows the language automatically. Settings are stored as JSON in AppData/Local/CalculusCalculator/CalculusCalculator/settings.json.

Save settings control which data is written when saving (all checked by default):

CategoryContents
DataFunction list, equation / inequality lists, vector list, cache contents
GeometryPlane geometry objects, solid geometry objects
InterfaceAll input texts, combo selections, formula view contents, tab numbers / language / theme

Unchecked categories are omitted from the file; when loading, a missing category leaves the current state unchanged. Project files use the .cca extension (JSON) and open by double-click.

10. Blockly Editor and Startup

Open the Blockly editor via "Features → Editor" and assemble blocks to build a visual computation flow without writing code:

  • Supports SymPy expressions and $-prefixed LaTeX; clicking Run executes the flow in order and shows intermediate results with LaTeX rendering.
  • Covers function definition, function analysis, derivative / integral, equation (systems), inequality (systems) and triangle solving.
  • Dual-mode code preview: switch between native SymPy code (SymPy only — copy and run anywhere) and library code (what the Run button executes), native code by default.
  • Projects can be saved and loaded, governed by the Save settings.

Startup: a lightweight splash screen is shown; the QWebEngine kernel is initialized only when the Blockly editor, the formula input or the Expression Calculator is first opened, and lazy loading further speeds up startup.
